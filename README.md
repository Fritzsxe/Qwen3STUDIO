# Qwen3STUDIO

An easy-to-use, web-based UI for **Qwen3-TTS** designed to make neural voice synthesis accessible to everyone—no coding required. 

Just launch it, open your browser, and start generating audio in seconds.

> ⚠️ **Note:** This is an initial release / early-stage version. Bugs are to be expected as development continues!

### Features
- **Zero-Code Interface:** Full control over Qwen3-TTS parameters through a clean, modern browser dashboard.
- **Real-Time Pipeline:** Powered by FastAPI, WebSockets, and PyTorch for live job status tracking and low-latency audio generation.
- **Multiple Modes:** Studio, Experience, and Mobile layouts for flexible workflows.
- **Local & Private:** Everything runs 100% locally on your machine.
